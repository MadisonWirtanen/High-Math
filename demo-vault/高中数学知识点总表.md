# 高中数学知识点总表（AI 录入查表用）

> **数据来源**：《【数学】考点地图(2.0).xlsx》→ 工作表「高中数学考点地图」>   
> **规模**：818 个知识点 · 21 章 · 74 节 · 4 类前缀>   
> **结构**：本表按 **「一级（章）→ 二级（节）→ 三级（知识点）」** 三级组织，与题库 YAML 的>   
> `chapter` / `section` / `knowledge` 三个字段一一对应。>   
> **用途**：AI 录入题目时，这三个字段**只能**逐字复制本表对应层级的原文——章取「一级（章）」列，>   
> 节取「二级（节）」列，知识点取「知识点（knowledge 取值）」列；不得改写、缩写、意译或自造名称。>   
> 三级知识点带【】前缀，前缀也是名称的一部分，必须保留。

## 二、三级字段的填写与选点说明

### 2.1 三个字段与三级的对应

| 层级 | 名称  | YAML 字段     | 本表取值位置                   |
| -- | --- | ----------- | ------------------------ |
| 一级 | 章   | `chapter`   | 「一级（章）」列（同 `## 第X章` 标题行） |
| 二级 | 节   | `section`   | 「二级（节）」列（同 `### 节名` 标题行） |
| 三级 | 知识点 | `knowledge` | 「知识点（knowledge 取值）」列     |

> 同一章、同一节在表内逐行重复出现，可整格直接复制；填入 YAML 时**去重**，并按本表出现顺序排列。

### 2.2 选点规则

1. 每题选 **1~4 个**知识点：先定「考的是什么知识」（优先【必备知识】），再定「以什么形式考」（【情境问题】等）。
2. 当两个知识点看起来都像时，**看「特殊标签解读」列**来区分边界；没有解读的，按名称字面从严匹配。
3. 「难度」列是该考点的星级，用于估算题目难度系数（见《AI 录入规范》第 9 节）。
4. 找不到完全对应时，宁可**少标、标主干**，也不要自造名称；确实无对应可留空。

### 2.3 三级联动规则

`chapter` / `section` 不是独立选的，而是由 `knowledge` 推导：

- 每个知识点在本表都能查到它所属的「二级（节）」和「一级（章）」；
- `section` = 所有知识点所属「节」的**去重**集合；`chapter` = 所有知识点所属「章」的**去重**集合；
- 必须满足包含关系：`section` 属于 `chapter`，`knowledge` 属于 `section`。

**示例**：某题 `knowledge: [【必备知识】余弦函数的图象与性质, 【必备知识】导数应用之求函数最值]`

- 【必备知识】余弦函数的图象与性质 → 章：三角函数，节：三角函数的图象与性质
- 【必备知识】导数应用之求函数最值 → 章：一元函数的导数及其应用，节：导数在研究函数中的应用
- 故 `chapter: [三角函数, 一元函数的导数及其应用]`，`section: [三角函数的图象与性质, 导数在研究函数中的应用]`
