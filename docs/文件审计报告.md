## 2. 过时文件识别与判断依据

### 2.1 🔴 `docs/AI排版提示词*.md`（6 个文件）—— 最高优先级

**判断依据（硬证据）**：

1. **与现行规范直接冲突。** 这 6 个文件全部写有类似条款：
   - `AI排版提示词.md`：「不对难度、知识点做任何猜测……全部留空」
   - `AI排版提示词_高考真题.md` / `_中考真题.md` / `_八上.md`：`difficulty: 留空`、`qid: 留空`

   而《AI录入规范 v2.1》**第 4 条铁律**明令：
   > `chapter` / `section` / `knowledge` 三级字段的每一项，必须**逐字**来自《知识点总表》对应层级……**严禁**改写、缩写、意译、拼接或自造名称。

   → 旧提示词让人「留空」，新规范要求「查表填满」，**二者不可能同时遵守**。

2. **日期早于规范。** 6 个文件中 5 个是 `10-08 16:21` 的批次产物，规范落款 `2026-10-09`（内部 v2.1）。

3. **结构缺失。** 旧文件完全没有：
   - 三级 `chapter` / `section` / `knowledge` 查表纪律
   - `[选]` / `[填]` 空格标记规则（不得出现在 `$...$` 内）
   - qid 生成规则、文件命名与冲突处理、只读边界
   - 四类【】前缀（必备知识/情境问题/能力素养/思想方法）

4. **内容高度重复。** `_中考真题` / `_八上` / `_高考真题` 三个文件规则正文几乎逐字相同，**仅开头一句"你是XX数学题库整理专家"不同**。

5. **存在明显的复制粘贴残留。** `AI排版提示词_八上.md`（初中八年级上版）开头仍写着"**高考真题**"—— 文件名与内容不符的铁证。

- 但重做示例题需要**逐题查表重标知识点**，工作量不小，且涉及"改题目内容"——按你的硬约束，这必须**单独征求同意**。
