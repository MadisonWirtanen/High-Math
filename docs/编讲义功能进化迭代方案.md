# HighMath 编讲义功能 · 进化迭代方案

> 版本：v1.0 ｜ 日期：2026-10-10 ｜ 状态：**待审批**  
> 基线版本：HighMath v2.1.1 ｜ 对标对象：教研云.word（word.jiaoyanyun.com）、Question-Manager、QuestionBank

---

## 0. 一句话结论

当前"编讲义"已经具备**模块化编排 + 7 种模块 + 试题篮挂题 + 草稿自动保存 + Word/zip 导出**的核心骨架，是一个能用的"讲义生成器"。  
但它还停留&#x5728;**"生成 markdown → 交给 pandoc/docx 库产出 Word"**&#x7684;单向管线，缺少三样东西：

1. **所见即所得的 A4 分页预览**（用户看到的不是"排好的页面"，而是 markdown 源码的渲染）；
2. **教学法层面的专业组件**（知识卡片、例题卡片、变式训练、提示框、答题留白、评分栏）；
3. **双版本（学生版/教师版）一键体系的完整落地**（目前只有"是否含解析"一个开关）。

本方案给出**四层进化路线（L1 版面呈现 → L2 教学组件 → L3 双版本与答题区 → L4 智能化）**，共 **17 项具体功能**，按 P0/P1/P2 分级。**所有功能均在现有 `HandoutModule` 模型上叠加扩展，不触碰题库、不改动题目文件格式。**

### 1.2 关键短板（对照截图与竞品）

- ❌ **无 A4 分页预览**：预览是连续滚动的 markdown，看不到"第几页""跨页断裂""留白是否够写"。
- ❌ **无答题留白 / 答题区**：学生版无法按题型预留书写空间（选择/填空/解答的物理高度不同）。
- ❌ **无页眉 / 页脚 / 页码 / 水印**：`HandoutSettings` 里根本没有这些字段（只有页内的"密封线"降级为一行文字）。
- ❌ **无分栏**：截图里的对照/小题并排做不到。
- ❌ **无专业教学卡片视觉**：模块只映射到 heading + 文本，没有边框、底色、图标、阴影等"卡片感"。
- ❌ **学生版/教师版不是一等公民**：靠 `answerPosition` + `includeSolution` 拼凑，不能一次导出两份。
- ❌ **无选项排列控制**：`optionLayout` 字段存在于 `HandoutSettings` 但**讲义页 UI 里没有入口**（只有组卷/服务端在用）。
- ⚠️ **Word 导出双轨不稳定**：依赖 pandoc 是否安装；兜底的 `docxFallback` 能力弱（无多级编号、无页眉页脚）。

## 4. L1 · 版面呈现层（P0 优先，收益最大）

> 目标：把"markdown 预览"升级为**所见即所得的 A4 分页纸**，让老师在编辑时就知道"印出来长什么样"。

### F1.1 A4 分页预览（P0 · 核心）

- **做法**：`handout/page.tsx` 的预览区改为 `<iframe>` + Paged.js polyfill。把 `buildDocumentMarkdown()` 的 markdown 先用 `marked` 转 HTML，注入 `@page` 样式后交给 Paged.js 分页。
- **产出**：真实分页的纸张视图，每页带页边距、页码，跨页处自动断裂；支持缩放（50%/75%/100%）。
- **代码影响**：新增 `src/lib/pagedPreview.ts`（纯前端）；`previewMode` 分支改造。**不触碰 handout.ts 生成逻辑**。
- **依赖**：`pagedjs`（MIT，约 300KB，可放 `public/` 动态加载，不进主包）。

### F1.2 页眉 / 页脚 / 页码（P0）

- **做法**：`HandoutSettings` 新增字段（**注意：这是 UI 设置，不写回题库，符合硬约束**）：
  ```
  headerText: string          // 页眉文本，支持 {title}/{date}/{page}
  footerText: string          // 页脚文本
  showPageNumber: boolean     // 页码
  pageNumberFormat: string    // 如 "第 {page} 页 / 共 {pages} 页"
  pageNumberStart: number     // 起始页码
  ```
- **实现**：Paged.js 的 `@page { @top-center { content: ... } }` + `counter(page)`；Word 端通过 pandoc `--reference-doc` 或 `docx` 库的 header/footer 实现。
- **取值来源**：讲义名、日期、页码自动。

### F1.3 水印（P1）

- **做法**：CSS `@page` 背景层平铺半透明文字（如"内部资料 请勿外传"）；Word 端用 docx 库的 header 水印图片/文本框。
- **字段**：`watermarkEnabled / watermarkText / watermarkOpacity`。

### F1.4 分栏（P0 · 高频刚需）

- **做法**：模块级属性 `columns: 1 | 2 | 3 | 4`，主要作用于**选项**与**小题**的排列：
  - 选项 1 列 / 2 列 / 4 列（直接对标教研云"选项排列设置一列/两列/四列"）；
  - 模块级双栏（如"辨析题左右对照"）。
- **实现**：`@page` 内用 CSS `column-count`；Word 端 pandoc 暂不支持分栏，**标注为"仅预览/PDF 生效"**，或走 docx 库的 column 支持（需评估）。
- **代码影响**：`handout.ts` 的 markdown 生成需支持"选项打包成表格"的降级路径（Word 兼容），CSS 分栏只在 HTML/PDF 路径生效。

### F1.5 题号与编号体系增强（P1）

对标教研云，补齐：

- **编号样式**：`1.` / `（1）` / `①` / `一、` / `第n题` —— 现有 `numberFormat` 已支持自定义模板，**只需加"样式预设一键切换"UI**；
- **标题编号**：连续编号 / 每级重排 / 无编号 / 自定义前缀（现有 `autoNumber` + `restartPerGroup` 已有基础，需补 UI 与"编号样式"）；
- **标题后仅一题无题号**（教研云特色，避免"一、选择题 1. "重复）；
- **隐藏空标题**（只有标题没题目的模块自动隐藏）。

### F1.6 Word 导出兜底增强（P1）

- **问题**：现在 pandoc 缺失时，`docxFallback` 能力弱——没有多级编号、页眉页脚、分栏，导出效果与预览差异大。
- **做法**：用已装的 `docx` npm 库重写兜底渲染：
  - 用 `numbering` 配置实现**真正的 Word 多级编号**（而非把 `1.` 写成文本）；
  - 用 `Header`/`Footer` 实现页眉页脚页码；
  - 表格化选项实现"4 列选项"。
- **收益**：无论用户装没装 pandoc，导出质量一致。

## 5. L2 · 教学组件层（P1，产品差异化关键）

> 目标：把"模块"从"标题+题"升级为**有教学语义、有视觉形态的卡片**。这是从"能排版"到"好讲义"的分水岭。

### F2.1 卡片化视觉体系（P0）

给每种模块定义**视觉皮肤**（左侧色条 + 图标 + 浅底色 + 圆角），在编辑区、预览区、导出 HTML/PDF 三处统一：

| 模块       | 视觉                  |
| -------- | ------------------- |
| 🏷️ 总标题  | 居中大字 + 副标题 + 分隔线    |
| 📌 知识点标题 | 左色条 + 编号徽章          |
| 📖 知识点讲解 | 浅蓝底 + "要点"图标        |
| 💡 例题讲解  | 浅黄底 + "例"徽章 + 边框    |
| ✏️ 真题练习  | 浅灰底 + "练"徽章         |
| 📝 自由文本  | 无皮肤                 |
| ⚠️ 警示/易错 | **新增**：浅红底 + "易错"图标 |
| 💬 提示框   | **新增**：浅绿底 + "提示"图标 |

### F2.2 新增教学模块（P1）

在现有 7 种基础上扩展（`MODULE_META` 加条目即可，**展开逻辑复用 `flattenModules`**）：

1. **变式训练卡（`variation`）** —— 挂在例题后，标题"变式 n"，题目区 + 留白；
2. **提示框 / 警示框（`callout`）** —— `variant: 'tip' | 'warn' | 'note'`，纯正文 + 视觉皮肤；
3. **方法总结（`method`）** —— "解题方法：……"，带图标；
4. **答题留白区（`blank`）** —— 见 L3；
5. **评分栏（`scorebar`）** —— 见 L3。

### F2.3 模块模板（P1）

- **做法**：把"一组模块"存为模板（如"高三一轮复习讲义骨架"= 总标题 + 知识点标题 + 知识点讲解 + 例题 + 变式 + 真题练习）。
- **复用**：`highmath.handoutTemplates` localStorage key **已存在**，只需补 UI 与"套用模板"逻辑。
- **多形态预设**（借鉴 Question-Manager 的四形态）：新建时选"试卷 / 讲义 / 练习单 / 错题集"，各自一套默认模块 + 默认设置。

### F2.4 格式刷与批量操作（P2）

- 格式刷（复制模块的排版属性到另一模块）；
- 批量：批量设置分值、批量移除题目、批量切换模块皮肤。

## 6. L3 · 双版本与答题区（P1，直接对标教研云核心卖点）

> 目标：一次编辑，**一键产出学生版 + 教师版 + 答题卡版**三份，而不是靠开关手动导两次。

### F3.1 学生版 / 教师版（P0）

- **做法**：新增"输出模式"概念 `OutputMode = 'student' | 'teacher' | 'both'`：
  - **学生版**：隐藏答案、隐藏解析、可选隐藏知识点标注；**按题型预留答题留白**；
  - **教师版**：完整答案 + 解析 + 教学批注；
  - **both**：导出时一次生成两个文件（或一个 zip）。
- **实现**：`buildDocumentMarkdown()` 增加 `outputMode` 参数，内部决定是否输出答案块；留白由 L3.2 负责。
- **对现有影响**：`answerPosition` / `includeSolution` 收敛为"教师版内部设置"，学生版强制 none。

### F3.2 答题留白区（P0 · 高价值）

- **做法**：新增 `BlankBlock` / 模块属性 `answerSpace: number`（预留高度，单位行或 mm）：
  - 选择题：留 0~1 行（通常不留白）；
  - 填空题：留 1~2 行；
  - 解答题：留 6~15 行（可配置）；
  - 可"按题型自动估算"：`autoBlankByType`。
- **实现**：
  - HTML/PDF：`<div class="answer-space" style="height:Xmm">`；
  - Word：空段落 ×N 或带下划线的空行。
- **标注**：仅学生版生效，教师版不产生留白。

### F3.3 评分栏 / 批改区（P2）

- **做法**：题号右侧或题目下方加"得分：\____"评分栏（对标教研云"试题模版评分栏选中"）；
- **可批改版**：预留批改勾选框。


### F3.4 答题卡 / 答题区（P2）

- 生成独立"答题卡"页：选择题填涂区（A B C D 圆圈）、填空/解答题作答区 —— 对标 Question-Manager 的"练习单/试卷"形态。

## 7. L4 · 智能化（P2，中长期）

> 目标：从"手工编排"进阶到"AI 辅助编排"。**需要 LLM，属于可选模块**。

### F4.1 AI 讲义生成（P2）

- 对标教研云"输入参考讲义，帮你生成一份讲义"：
  - 输入：一个知识点/章节 + 题库范围；
  - 输出：自动排出"知识点标题 → 知识点讲解（AI 写）→ 例题（题库选题）→ 变式 → 真题练习"的模块骨架。
- **实现**：调 LLM 生成"模块 JSON"，套用 F2.3 模板填入。**需要用户配置 API Key**（放进设置页，密钥只存本地 `%APPDATA%\HighMath\`，符合现有 config 边界）。

### F4.2 智能分组（P2）

- 按知识点/难度/题型把一批题自动分组，生成多个"例题/练习"模块（对标"智能分组""按一级标题分组"）。

### F4.3 AI 知识点补全 / 相似题推荐（P2）

- 对标教研云"知识点不完整，请给试题纠错"+ QuestionBank 的 RAG 知识点映射；
- 相似题推荐（对标 `queSimCity`）。

> ⚠️ **硬约束提醒**：AI 补全知识点属于"修改题目内容"，**必须走独立确认流程**（见 §10），不得自动写回题库。

## 9. 技术选型建议

| 项             | 选型                            | 理由                                                         |
| ------------- | ----------------------------- | ---------------------------------------------------------- |
| 分页            | **Paged.js (MIT)**            | 唯一成熟的浏览器端 Paged Media 实现；纯前端，零服务端；与现有 markdown→HTML 管线天然契合 |
| markdown→HTML | `marked`（已装）                  | 复用                                                         |
| 公式            | KaTeX（已装）                     | 复用，无需换 MathJax                                             |
| Word 主通道      | pandoc（已有）                    | 保留                                                         |
| Word 兜底       | `docx` npm（已装）增强              | 重写兜底渲染，支持多级编号/页眉页脚                                         |
| PDF           | 浏览器打印 + `@page`               | 配合 Paged.js，"另存为 PDF"即高清 A4                                |
| 状态管理          | 现有 React state + localStorage | 不为本轮引入新状态库                                                 |

**不引入**：重型富文本编辑器（ProseMirror/Slate）——我们的编辑是"模块卡片流"，不是自由富文本，引入会把简单问题复杂化。

## 10. 硬约束遵守说明（题库零影响）

> 用户原话：「我比较关心我的题库会不会受到影响，我不希望更改题库的架构，题库还是保持原样」

本方案**逐项核对**，全部满足：

| 约束          | 本方案如何处理                                                                                   |
| ----------- | ----------------------------------------------------------------------------------------- |
| 不新增 YAML 字段 | ✅ 所有新字段（页眉、水印、留白、输出模式）都在 `HandoutSettings` / `HandoutModule`——**只存在于草稿与 UI state，不写题目文件** |
| 不在题库目录新建文件  | ✅ 无任何新的题库侧写盘                                                                              |
| 不修改题目内容     | ✅ 生成管线只读；AI 补知识点（F4.3）**单列为需独立授权的例外**                                                     |
| 写入路径不变      | ✅ 无新增写入路径；草稿仍写 `%APPDATA%\HighMath\drafts\`                                               |
| 导出只读        | ✅ 导出仍是"读题 → 生成 markdown → 交给 pandoc/docx"                                                 |

**唯一需要单独授权的项**：F4.3 的"AI 知识点补全"若被采纳，属于修改题目内容，**必须单独提出、单独确认、单独实现**，绝不夹在本方案里一起做。

## 11. 风险与取舍

| 风险           | 说明                     | 缓解                                                |
| ------------ | ---------------------- | ------------------------------------------------- |
| Paged.js 体积  | ~300KB，且需在 iframe 内运行  | 动态 `import()`，仅预览时加载；不进首屏包                        |
| Word 分栏不支持   | pandoc 无法可靠输出 Word 分栏  | 分栏标记为"预览/PDF 生效"，Word 走表格降级                       |
| 预览与 Word 有差异 | Web 排版 ≠ Word 排版       | 明确定位：**预览=PDF 效果**；Word 是"可编辑交付物"，允许有限差异；在 UI 上标注 |
| 学生版留白估算不准    | 按题型自动留白可能过多/过少         | 提供手动覆盖 + "按行数"精确设置                                |
| 现有草稿兼容       | `HandoutSettings` 新增字段 | 已有 `normalizeSettings()` 兜底合并，天然兼容旧草稿             |
| 功能膨胀         | 17 项一次做完会失控            | 严格 P0→P1→P2 分三轮，每轮独立可交付、可回归                       |
